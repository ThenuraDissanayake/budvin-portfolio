# Budvin Dissanayake — Portfolio

My personal portfolio site: **[budvin-portfolio.vercel.app](https://budvin-portfolio.vercel.app)**

## Built with

- [Next.js 14](https://nextjs.org) (App Router) and TypeScript
- Tailwind CSS
- Framer Motion
- Deployed on Vercel

## Project structure

- `src/app/` — pages and layout
- `src/components/` — page sections and shared UI
- `src/data/portfolio.ts` — all site content (projects, skills and experience)

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
